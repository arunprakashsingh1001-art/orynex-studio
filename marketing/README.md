## Automation model

This kit standardizes repeatable work and makes handoffs consistent. It does **not** publish to Instagram/YouTube, access Google Ads, or send customer messages automatically. Those actions require platform connections, permissions, and often approved API access. Do not store credentials or access tokens in these files or in Git.

**Default safety gates:** draft → factual/brand review → platform-format check → owner approval → publish manually or through an approved scheduler → log URL and results. Paid campaigns remain paused until a budget and tracking have been approved.

## Brand and truth rules

- Use the matte black/charcoal and vivid orange visual identity.
- Keep layouts readable on mobile, captions concise, and CTA singular.
- Use actual portfolio work or clearly label visuals as concepts.
- Never invent client names, testimonials, case studies, awards, performance metrics, or guarantees.
- Do not imply an illustrative UI is a shipped client project.
- Respect music, font, image, and footage licenses.
- Ask permission before sharing client assets or confidential project information.
- Avoid spammy mass DMs, misleading engagement bait, and irrelevant hashtags.
